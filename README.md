# Project Alenna — Moonlit Parry

Demo game hành động 2D (Unity 6) lấy cảm hứng từ Momodora: nữ kiếm sĩ tóc trắng với thanh katana, rừng anh đào dưới trăng, xác sống và boss kỵ sĩ cưỡi ngựa. Lối chơi xoay quanh **parry** (đỡ đòn đúng lúc), lộn né và kết liễu.

## Chơi thử (Windows)

1. Vào mục **Releases** của repo này, tải file `MoonlitParry_Windows.zip`.
2. Giải nén ra một thư mục.
3. Chạy `MoonlitParry.exe`.

## Điều khiển

| Phím | Hành động |
|---|---|
| A / D | Di chuyển |
| Space | Nhảy (giữ lâu nhảy cao hơn) — S + Space: xuống khỏi bục |
| Chuột trái / J | Chém (bấm tiếp để ra chuỗi 3 đòn) |
| Chuột phải / K | Parry — bấm đúng lúc bị đánh để đỡ hoàn hảo |
| Shift / L | Lộn né |
| 1 / H | Uống bình máu |
| F | Kết liễu kẻ địch đã kiệt sức |
| R | Nghỉ ở lửa trại / thử lại |
| Esc / P | Tạm dừng (âm lượng, độ khó, thoát game) |

## Mở dự án

Mở thư mục repo bằng Unity **6000.6.4f1** (Unity Hub ▸ Add project from disk), mở scene `Assets/MoonlitParry/Scenes/MoonlitParry.unity` rồi bấm Play. Menu **Moonlit Parry ▸ Build Windows (zip)** tạo bản build chia sẻ được.
